What Dydra Studio Is

Dydra Studio is a single-page web application. From it you can:

  • Manage RDF data repositories
  • Execute SPARQL queries
  • Import and export data
  • Create and manage SPARQL views (saved queries)
  • Edit account and repository metadata
  • Collaborate with other users
  • Ask a language model about your data, and compose whole pages from several queries
  • Arrange the interface itself, and share those arrangements

Start Here

Open the Application

Dydra Studio runs in your web browser. Go to the login page at:

URL

https://dydra.com/ui/user

The application shows the login page when you first open it, and whenever you are not signed in.

Browser Requirements

The application needs a modern web browser with:

  • JavaScript enabled
  • ES6+ JavaScript support
  • History API support (or hash-based routing fallback)

Chrome, Firefox, Safari, and Edge all qualify, in their current versions.

The Two Interfaces

Dydra Studio offers two interfaces:

  • User App: manage your account, work with repositories, run SPARQL queries, and import or export data
  • Console: administer the system as a whole. Its own manual covers it.

This manual covers the User App.

Quick Start

To begin:

  1. Go to https://dydra.com/ui/user in your web browser
  2. Follow the Login instructions and sign in
  3. Once signed in, reach every feature through the navigation interface
