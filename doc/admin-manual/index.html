Preface

This manual describes the Dydra administrative console: a browser-based single-page application that provides privileged access to system-level operations not available through the ordinary user interface. It is intended for personnel who hold administrative credentials on a Dydra installation and who require precise, authoritative documentation of the console's capabilities and operational model.

The administrative console is accessible at https://dydra.com/ui/admin. It is distinct from the user application (https://dydra.com/ui/user) in both purpose and privilege level. Where the user application permits an authenticated account to manage its own repositories and views, the administrative console permits qualified operators to inspect and modify the system as a whole: every account, every repository, and the complete service history.

Privilege Levels

The console distinguishes two classes of authenticated user:

ClassConditionCapabilities
Administrator Account's administrator_of property includes http://dydra.com Full read/write access: create and delete accounts, repositories, and invitations
Operator Any authenticated account without administrator designation Read-only access: inspect accounts, repositories, and all history tabs

Throughout this manual, operations marked (Admin only) are unavailable to operators. All other operations are available to both classes.

Notation Conventions
